# ✅ Checklist Completo - Lançamento da Rifa

## 📋 PRÉ-LANÇAMENTO

### 🎯 Planejamento (1-2 semanas antes)

- [ ] Definir o prêmio principal
- [ ] Definir prêmios secundários (2º e 3º lugar)
- [ ] Calcular custos totais
- [ ] Definir preço da cota
- [ ] Definir quantidade de números
- [ ] Escolher data do sorteio
- [ ] Criar regulamento
- [ ] Definir números da sorte

### 📸 Conteúdo (1 semana antes)

- [ ] Tirar fotos profissionais do prêmio
  - [ ] Foto principal (destaque)
  - [ ] Fotos de detalhes
  - [ ] Fotos de diferentes ângulos
  - [ ] Mínimo 5 fotos de qualidade

- [ ] Gravar vídeos
  - [ ] Tour completo pelo prêmio
  - [ ] Vídeo de apresentação (30-60s)
  - [ ] Vídeo explicando como participar

- [ ] Criar artes gráficas
  - [ ] Banner para Instagram (1080x1080)
  - [ ] Stories (1080x1920)
  - [ ] Capa do Facebook (820x312)
  - [ ] Thumbnail YouTube (1280x720)

### 🌐 Configuração do Site

- [ ] Abrir admin.html
- [ ] Fazer login no painel
- [ ] Configurar informações:
  - [ ] Título da rifa
  - [ ] Subtítulo
  - [ ] Preço da cota
  - [ ] URL da imagem principal
  - [ ] URL do vídeo (opcional)
  - [ ] Descrição completa dos prêmios
  - [ ] Números da sorte
  - [ ] Link de checkout

- [ ] Testar o site:
  - [ ] Abrir index.html
  - [ ] Verificar se imagem carrega
  - [ ] Verificar se preço está correto
  - [ ] Testar seletor de quantidade
  - [ ] Testar cálculo do total
  - [ ] Testar botão "Participar"
  - [ ] Verificar números da sorte
  - [ ] Ler descrição dos prêmios
  - [ ] Abrir regulamento

- [ ] Testar em dispositivos:
  - [ ] Celular (Chrome)
  - [ ] Celular (Safari)
  - [ ] Tablet
  - [ ] Desktop

### 💳 Configuração do Checkout

- [ ] Criar conta na plataforma (Kiwify/Kirvano/Cakto)
- [ ] Criar produto:
  - [ ] Nome: "Rifa [Nome do Prêmio]"
  - [ ] Preço: R$ 7,00 (ou seu preço)
  - [ ] Descrição clara
  - [ ] Imagem do prêmio

- [ ] Configurar formas de pagamento:
  - [ ] PIX
  - [ ] Cartão de crédito
  - [ ] Boleto

- [ ] Configurar e-mail de confirmação
- [ ] Testar compra (modo teste)
- [ ] Copiar link de checkout
- [ ] Colar no painel admin

### 📱 Redes Sociais

- [ ] Instagram:
  - [ ] Criar/otimizar perfil
  - [ ] Bio atrativa com link
  - [ ] Foto de perfil profissional
  - [ ] Destaques organizados

- [ ] Facebook:
  - [ ] Criar página ou usar perfil
  - [ ] Capa atrativa
  - [ ] Informações completas
  - [ ] Link do site

- [ ] WhatsApp:
  - [ ] WhatsApp Business instalado
  - [ ] Perfil profissional
  - [ ] Mensagem de boas-vindas
  - [ ] Respostas rápidas configuradas
  - [ ] Catálogo criado

- [ ] YouTube (opcional):
  - [ ] Canal criado
  - [ ] Banner personalizado
  - [ ] Descrição completa

### 📊 Ferramentas de Análise

- [ ] Google Analytics configurado
- [ ] Facebook Pixel instalado
- [ ] Links rastreáveis criados
- [ ] Planilha de controle preparada

### 🎨 Material de Divulgação

- [ ] Posts para Instagram (mínimo 5)
- [ ] Stories para Instagram (mínimo 10)
- [ ] Posts para Facebook (mínimo 3)
- [ ] Mensagens para WhatsApp (3 versões)
- [ ] Vídeos para TikTok (mínimo 3)
- [ ] E-mails prontos (confirmação, lembrete, resultado)

## 🚀 DIA DO LANÇAMENTO

### Manhã (8h-12h)

- [ ] Verificar se tudo está funcionando
- [ ] Fazer post teaser no Instagram
- [ ] Fazer post teaser no Facebook
- [ ] Atualizar status do WhatsApp
- [ ] Avisar amigos próximos

### Tarde (12h-18h)

- [ ] Publicar post principal no Instagram
- [ ] Publicar post principal no Facebook
- [ ] Enviar mensagens para grupos do WhatsApp
- [ ] Fazer stories a cada 2 horas
- [ ] Responder comentários e mensagens

### Noite (18h-23h) - HORÁRIO NOBRE

- [ ] Fazer live de lançamento (opcional)
- [ ] Publicar stories com urgência
- [ ] Enviar mensagens diretas para contatos
- [ ] Responder todas as dúvidas
- [ ] Atualizar contador de vendas

## 📈 DURANTE A CAMPANHA

### Diariamente

- [ ] Postar 1-2 stories
- [ ] Responder mensagens em até 1 hora
- [ ] Atualizar números vendidos
- [ ] Compartilhar compras recentes
- [ ] Fazer 1 post no feed (dia sim, dia não)

### A cada 3 dias

- [ ] Fazer vídeo curto (Reels/TikTok)
- [ ] Atualizar depoimentos
- [ ] Criar senso de urgência
- [ ] Fazer promoção relâmpago

### Semanalmente

- [ ] Analisar métricas
- [ ] Ajustar estratégia
- [ ] Criar novo conteúdo
- [ ] Fazer parcerias
- [ ] Responder FAQ público

### 1 Semana Antes do Sorteio

- [ ] Intensificar divulgação
- [ ] Fazer contagem regressiva
- [ ] Criar urgência ("últimos números")
- [ ] Fazer promoção final
- [ ] Avisar sobre transmissão ao vivo

### 1 Dia Antes do Sorteio

- [ ] Confirmar horário do sorteio
- [ ] Testar transmissão ao vivo
- [ ] Enviar e-mail para todos os participantes
- [ ] Fazer stories a cada hora
- [ ] Criar expectativa

## 🎊 DIA DO SORTEIO

### Antes do Sorteio

- [ ] Verificar extração da Loteria Federal
- [ ] Preparar ambiente para live
- [ ] Testar câmera e microfone
- [ ] Avisar nos stories (1 hora antes)
- [ ] Avisar no WhatsApp (30 min antes)

### Durante o Sorteio

- [ ] Iniciar transmissão ao vivo
- [ ] Explicar como funciona
- [ ] Mostrar extração da Loteria
- [ ] Anunciar ganhadores
- [ ] Comemorar com participantes
- [ ] Agradecer a todos

### Depois do Sorteio

- [ ] Publicar resultado em todas as redes
- [ ] Enviar e-mail para todos
- [ ] Entrar em contato com ganhadores
- [ ] Salvar vídeo do sorteio
- [ ] Agradecer participantes

## 🏆 PÓS-SORTEIO

### Primeiras 24 horas

- [ ] Confirmar identidade dos ganhadores
- [ ] Publicar foto/vídeo dos ganhadores
- [ ] Compartilhar reação dos ganhadores
- [ ] Agradecer todos os participantes
- [ ] Anunciar próxima rifa (teaser)

### Primeira Semana

- [ ] Combinar entrega dos prêmios

- [ ] Fazer vídeo da entrega
- [ ] Pedir depoimento dos ganhadores
- [ ] Publicar tudo nas redes

### Até 30 Dias

- [ ] Entregar todos os prêmios
- [ ] Publicar comprovantes

- [ ] Agradecer novamente
- [ ] Planejar próxima rifa
