## 📞 SUPORTE E AJUDA

### Problemas Comuns

**"Não consigo fazer login no admin"**
→ Credenciais padrão: admin@rifa321.com / admin123
→ Altere em: admin.js

**"A imagem não aparece"**
→ Use link direto (termina em .jpg, .png)
→ Teste o link no navegador

**"O botão Participar não funciona"**
→ Configure o link de checkout no admin
→ Verifique se o link está correto

**"Perdi os dados ao limpar o cache"**
→ Use Firebase (veja README.md)
→ Faça backup regularmente

**"Como alterar as cores?"**
→ Edite style.css (variáveis no início)

**"Como mudar a senha do admin?"**
→ Edite admin.js (ADMIN_CREDENTIALS)
